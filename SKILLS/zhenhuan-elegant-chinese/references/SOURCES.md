# 研究來源與證據分級

本 skill 提煉的是語言方法，不是台詞語料庫。下列資料用於支持規則；短引僅供研究說明。

## A 級：主創本人或權威訪談

### 王小平談編劇方法

- 中國作家網，〈王小平：故事與人物在我心裡蟄伏〉，2020-10-21：
  https://www.chinawriter.com.cn/n1/2020/1021/c405057-31899574.html
- 要點：電視劇偏重以對話敘事；劇本須簡單明瞭；角色台詞要個性化，並對人物與情節起關鍵作用；好作品應兼具內涵與藝術品質。

### 「甄嬛體」的可辨識用詞

- 人民網，唐平，〈專訪鄭曉龍王小平：「羋月」是贏家「甄嬛」是怨婦〉，2016-01-20：
  http://culture.people.com.cn/BIG5/n1/2016/0120/c87423-28070489.html
- 要點：王小平談《羋月傳》刻意區分語言風格時，點名「真真」「極好的」等是需要避開的《甄嬛傳》式潛詞造句。這證明風格辨識不只在故事題材，也在微觀措辭。

### 王小平自述「十三道坎」

- 編劇幫轉載王小平文章，〈《甄嬛傳》編劇王小平：關於小說作者改行做編劇的〉，2015：
  https://www.sohu.com/a/31537001_154166
- 要點：精彩台詞是人物的靈魂；人物行為邏輯由情節與對話揭示；影視人物語言須惜墨如金。此來源是作者署名轉載，可信度高於一般評論，但仍次於作者官方出版物。

## B 級：學術研究

### 古詩詞在古裝劇中的功能

- 拉曼大學中文系學位論文，〈古詩詞在古裝劇裡的效用〉，2020：
  http://eprints.utar.edu.my/3996/1/fyp_CH_2020_LKPT_-_1800067.pdf
- 要點：詩詞可刻畫外貌與聲音、表達人物思想情感、推動情節、建立時代與文化氛圍；其凝練性可避免對白冗長。這支持「典故必須有功能」的規則。

### 修辭、節奏與文化負載

- 娜非沙・伊拉木，〈淺析美版《甄嬛傳》中的不可譯性〉，《現代語言學》，2024，DOI: 10.12677/ml.2024.129826：
  https://pdf.hanspub.org/ml2024129_782913709.pdf
- 要點：研究從語音、詞彙、語法與修辭討論台詞；指出韻律、文化意象、稱謂階序、雙關等難以完整移譯。文中「73 首詩詞、3 篇賦」是二手統計，未見原始計數方法，因此本 skill 不把該數字當成核心事實。

### 言外之意與語用機制

- 王巍峰，〈論《甄嬛傳》台詞的言外之意〉，《開封教育學院學報》，2015(5)。目前公開檢索只找到後續論文的書目引用，未取得可核對全文。
- 武玲燕，〈《後宮・如懿傳》人物對話言外之意的語用分析〉，鄭州大學／社科網：
  https://www.sinoss.net/uploadfile/2021/0415/20210415104828482.pdf
- 要點：後者不是《甄嬛傳》研究，但以會話含義理論整理聯想意義、情感意義、指示意義，以及雙關、引用、反諷等手段，可作為同類宮廷敘事的語用參照。引用時不可混稱為《甄嬛傳》證據。

## C 級：媒體評論與補充觀察

- 澎湃新聞轉載評論，〈被盤出包漿的《甄嬛傳》，11 年後怎麼還那麼火？〉：
  https://www.thepaper.cn/newsDetail_forward_18165743
- 要點：以安陵容、沈眉莊等為例觀察身份、性格與慣用語的差異，適合支持「人物聲紋」的實務分析；不是主創一手說法。

## 使用來源的規則

1. 主創自述用來確立創作原則；學術資料用來解釋語言機制；媒體評論只作補充例證。
2. 無法取得全文的論文，只能註明書目存在，不可臆測其結論。
3. 網路流傳的「經典台詞」若無劇集字幕、正式劇本或可靠出版物核對，不標為原劇台詞。
4. 不保存大量逐字台詞；需要分析時使用最短必要片段，轉而描述其功能。
